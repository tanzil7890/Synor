This source tree includes an **agent skill** that teaches AI coding agents how to build Synor v1 pipelines correctly — core concepts, API surface, common patterns, connectors, and best practices, all in one place.

The skill lives in the `skills/synor/` directory of the main repo.

## Why a skill?

Synor v1 is a fundamental redesign from v0. Without context, an LLM trained on older snapshots tends to hallucinate the wrong API (the v0 flow-builder DSL, deprecated decorators, missing `@syn.fn`, unstable component paths). The skill gives the agent a single concise reference covering:

- **Mental model** — observe change, assign stable work ownership, and reconcile declared outcomes through [processing components](../programming_guide/processing_component).
- **Core APIs** — `@syn.fn`, `mount` / `use_mount` / `mount_each`, `ContextKey`, `@syn.lifespan`, target state declarations.
- **Common patterns** — file transformation, vector embedding, LLM extraction, knowledge graphs.
- **Connectors** — PostgreSQL, SQLite, LanceDB, Qdrant, SurrealDB, Apache Doris, LocalFS, S3, Kafka, Google Drive.
- **Best practices** — memoization, stable component paths, vector schema with `Annotated[NDArray, KEY]`.

## Use with agent clients

| Client / workflow | Recommended setup |
| --- | --- |
| **Codex / Agent Skills-compatible clients** | Use `.agents/skills/synor` for repo-local discovery. In this Synor repo, checked-in `.agents/skills` symlinks expose the public skill and contributor playbooks automatically. |
| **Claude Code** | Use `.claude/skills/synor` in a project, or `~/.claude/skills/synor` globally. |
| **Cursor** | Copy `skills/synor/SKILL.md` into `.cursor/rules/synor.md`. |
| **Generic AGENTS.md / CLAUDE.md** | Link to, import, or summarize `skills/synor/SKILL.md` from your top-level agent instructions. |
| **Context7** | This repo's `context7.json` already indexes `skills/synor`; custom stacks can index the same folder. |
| **Custom RAG / agent stack** | Index the `skills/synor/` directory, including `references/`, as regular documentation. |

Agent Skills-compatible clients load a skill directory that contains `SKILL.md`.
If `.agents/skills/synor` is checked into your project, no extra install step is
needed for clients that scan that path.

Project-local install for Codex or other Agent Skills-compatible clients:

```sh
mkdir -p .agents/skills
cp -R skills/synor .agents/skills/synor
```

## Use with Claude Code

Claude Code auto-loads skills from `.claude/skills/` in the current project, or from `~/.claude/skills/` globally.

Project-local install (recommended for repos that build with Synor):

```sh
mkdir -p .claude/skills
cp -R skills/synor .claude/skills/synor
```

Global install:

```sh
mkdir -p ~/.claude/skills
cp -R /absolute/path/to/Synor/skills/synor ~/.claude/skills/synor
```

Once installed, Claude Code picks up the skill automatically when you ask it to build or modify a Synor pipeline.

## Use with other agents

The skill is plain Markdown — `SKILL.md` plus a few reference files. Any agent that accepts file-based context will work:

- **Cursor** — copy `skills/synor/SKILL.md` into `.cursor/rules/synor.md`.
- **Generic AGENTS.md / CLAUDE.md** — concatenate or `@import` `SKILL.md` from your top-level agent instructions file.
- **Context7** — use this repo's `context7.json` shape as a reference; it indexes `skills/synor` alongside docs and examples.
- **Custom RAG / agent stack** — index the `skills/synor/` directory like any other documentation source.
